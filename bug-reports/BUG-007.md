# BUG-007 — Sign out keeps Create account tab active after register

| | |
|--|--|
| Severity | Low |
| Priority | Low |
| Status | Open |
| Environment | Live demo + `app/static/app.js` |
| Area | Auth |
| Case | AUTH-12 |
| Labels | `ux` |

## Summary

After creating an account and clicking **Sign out**, the auth card still shows the **Create account** tab / button. `logout()` calls `showAuthView()` but does not reset `authMode` to `"login"`.

## Steps

1. Create a new account (Create account tab).
2. Click **Sign out**.
3. Look at the auth tabs and primary button label.

## Expected

Signed-out users land on **Sign in** (most common next action).

## Actual

**Create account** remains active; submit button still says “Create account.”

## Notes

Caught this while running my Playwright smoke — the test looked for a “Sign in” button after logout and timed out. Easy fix: call `setAuthMode("login")` on logout / when showing the auth view again.
