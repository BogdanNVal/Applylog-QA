# BUG-006 — Stats bar has no Rejected count

| | |
|--|--|
| Severity | Low |
| Priority | Low |
| Status | Open |
| Environment | Live demo + `index.html` stats section |
| Area | Stats |
| Case | STA-03 |
| Labels | `ux` |

## Summary

The API returns a `rejected` count (and `offer_rate`), but the dashboard tiles only show Applications, Waiting (applied), Interviews, Offers, Response rate, and Last 7 days. There is no **Rejected** tile.

## Steps

1. Create applications including at least one with status Rejected.
2. View the summary strip.

## Expected

Rejected is visible in the summary (or clearly documented that Response rate is the only place rejections appear).

## Actual

Rejected apps affect Response rate maths but have no dedicated count. Users must filter the table to see how many were rejected.

## Notes

Maybe on purpose — but when I see Waiting / Interviews / Offers, I expect Rejected nearby too. Right now I have to filter the table to count them. Filing as UX feedback, not a hard break.
